# Лісове Казино — Світ Ігор

Тривимірна гра-галерея на **Godot 4.7.2** з відкритою гірською долиною, атмосферним особняком-казино, підземним 4-зальним комплексом, мансардою-обсерваторією, гірською гоночною трасою, системою квестів та **19 вбудованими міні-іграми** (24 інтерактивні картини та виставкові триноги).

## Основні можливості

- **Особняк казино та зали**:
  - **Головна зала**: *Маріо*, *Тетріс*, *Змійка 3D*, *Бомбермен*, *Арканоїд*, *Космічна Аркада*, *Танчики*, рулетка, слот-автомати та Дошка квестів.
  - **Західна зала стратегій**: *Соккер*, *Шахи*, *Шашки*, *Уголки*, *Морський бій*.
  - **Східне крило**: *Пак-Лабіринт*, сходи вгору на мансарду та спуск у підвал.
  - **Мансарда**: оглядова тераса з інтерактивним біноклем для спостереження за долиною та гоночною трасою (плавний зум `2x–14x`).
  - **Розширений підвал (4 зали)**:
    1. **Картковий клуб**: *Дурак*, *Блекджек*, *Покер*, кнопка ВІП-диско.
    2. **Виставочний зал із триногами**: 6 мольбертів-триног із новими іграми (**2048**, **Зума**, **Пазли**) та колекційними стендами, Золотий Кубок.
    3. **Винний погріб**: винні стелажі, бочки, артефакт «Винна Амфора 1898» і ретро-стенд.
    4. **Таємне сховище банку**: сейф із бонусними фішками, золото, «Королівський Сапфір» і стенд.
- **Відкрита долина та гірська траса**:
  - Ландшафт на `Terrain3D`, динамічне небо й цикл погоди (`Sky3D`), випадкова лісова та прибережна флора (`CosmoTreeGen`, `SimpleGrassTextured`), 3 озера, дика фауна та процедурний аудіорушій (`AudioSfx`).
  - Звивиста дорога з бруківки від казино до піт-стопу та лісові стежки до озера й вівтаря погоди.
  - Замкнена гірська гоночна траса навколо локації: похилі повороти, буст-зони, стрибок через прірву, 360° вертикальна «мертва петля» та **3 AI-суперники**, що їздять безперервно навіть поза гонкою.
- **Система квестів (`[Q]`)**:
  - 6 квестів із підрахунком фішок та журналом (*Таємниці Підземелля*, *Мисливець за Реліквіями*, *Поціновувач Новинок*, *Сейф Сховища й ВІП-Диско*, *Король Гірської Траси*, *Спостерігач Долини*).
- **Меню налаштувань**:
  - Підменю **Налаштування** об'єднує вкладки **Дисплей** (роздільна здатність, віконний/повноекранний режим, VSync, ліміт FPS) та **Графіка** (пресети 0–5, render scale, згладжування, тіні, SDFGI/SSAO/SSR/Bloom/туман, щільність рослинності, дальність, погода, гучність).

## Встановлення та запуск (Windows)

1. Запустіть `1_SETUP.bat` — скрипт автоматично завантажить **Godot 4.7.2**, плагіни (`Terrain3D`, `Sky3D`, `SimpleGrassTextured`, `CosmoTreeGen`), PBR/CC0 асети (`_fetch_assets.ps1`), створить конфіг і імпортує проєкт.
2. Запустіть гру одним із лаунчерів:
   - `2_RUN.bat` — інтерактивний вибір лаунчера (`2_RUN_Vulkan` / `2_RUN_DX12` / `2_RUN_OpenGL`) клавішами `↑` / `↓` (або `1–3`), підтвердження — `Enter`, вихід — `Esc`;
   - `2_RUN_Vulkan.bat` — примусовий запуск на **Vulkan / Forward+**;
   - `2_RUN_DX12.bat` — **Direct3D 12 / Forward+**;
   - `2_RUN_OpenGL.bat` — режим сумісності **OpenGL 3**.

## Керування

| Дія | Клавіші |
|---|---|
| Рух / Спринт / Стрибок | `WASD` або стрілки / `Shift` / `Пробіл` |
| Взаємодія (картини, триноги, гаджети, болід, бінокль) | `E` або `ЛКМ` |
| Журнал квестів / Ліхтар / Пауза | `Q` / `F` / `Esc` |
| Болід на трасі | `W/S/A/D` кермо, `Shift`/`Пробіл` нітро, `V` камера, `R` повернення на трек, `Esc` вихід |
