# Лісове Казино — Світ Ігор

Тривимірна гра-галерея на **Godot 4.7.2** з відкритою гірською долиною, атмосферним особняком-казино, підземним 4-зальним комплексом, мансардою-галереєю, гірською гоночною трасою, системою квестів та **34 унікальними міні-іграми** (настінні картини й виставкові триноги).

## Основні можливості

- **Особняк казино та зали**:
  - **Головна зала (7 картин + ігрові автомати + карта)**: *Маріо*, *Тетріс*, *Змійка 3D*, *Бомбермен*, *Арканоїд*, *Космічна Аркада*, *Танчики*.
  - **Повноцінна 3D-рулетка у центрі залу**: європейське колесо на 37 секторів (`0–36`), плавний наїзд камери, інтерактивне ігрове сукно зі ставками (`10 / 25 / 50 / 100` фішок, числа, дюжини, пар/непар, `1–18/19–36`, червоне/чорне), 3D-фішки на столі та фізична 3D-кулька по ободу.
  - **Однорукі бандити (слот-автомати)**: анімовані 3-барабанні векторні слоти з почерговою фіксацією та виграшем фішок.
  - **Карта ігор на виході (`34` ігри)**: підсвічений 3D-стенд зліва перед південним виходом із детальним планом усіх залів (відкривається у збільшеному вікні по `[E]`), а також Дошка квестів.
  - **Західна зала стратегій (5 картин)**: *Соккер*, *Шахи*, *Шашки*, *Уголки*, *Морський бій*.
  - **Східне крило (1 картина)**: *Пак-Лабіринт*, сходи вгору на мансарду та спуск у підвал.
  - **Мансарда (10 триног + оглядова тераса)**:
    - Галерея 10 міні-ігор: *Пітон* (3D з 18 біомами й текстурами), *Гекса*, *Сокобан* (16 рівнів), *П'ятнашки*, *Хрестики-Нулики*, *Теніс (Pong)*, *Меморі*, *Кодовий замок*, *Бики та Корови*, *Балда*.
    - Оглядова тераса з інтерактивним **біноклем** для спостереження за долиною та трасою (зум `2x–14x`).
  - **Розширений підвал (4 зали, 11 ігор)**:
    1. **Картковий клуб**: *Дурак*, *Блекджек*, *Покер*, кнопка ВІП-диско.
    2. **Виставочний зал із триногами**: *2048*, *Зума*, *Пазли*, *Самоцвіти*, *Сапер*, *Косинка*, Золотий Кубок.
    3. **Винний погріб**: винні стелажі, бочки, артефакт «Винна Амфора 1898» і гра *Сокіл Долини*.
    4. **Таємне сховище банку**: сейф із бонусними фішками, золото, «Королівський Сапфір» і гра *Судоку*.
- **Відкрита долина та гірська траса**:
  - Ландшафт на `Terrain3D`, динамічне небо й цикл погоди (`Sky3D`), флора (`CosmoTreeGen`, `SimpleGrassTextured`), **3 прозорі озера з підводними водоростями, рибками та рельєфом дна**, дика фауна (`AudioSfx` + анімовані GLB тварини та птахи).
  - Звивиста дорога з бруківки від казино до піт-стопу та лісові стежки до озера й вівтаря погоди.
  - Замкнена гірська гоночна траса навколо локації: **4 вертикальні 360° «мертві петлі»**, трамплін-стрибок через прірву, похилі віражі, буст-зони, перегони на 3 кола та **4 AI-суперники** (зі сліпстрімом і прискоренням обгону), що курсують безперервно.
- **Система квестів (`[Q]`)**:
  - 6 квестів із підрахунком фішок та журналом (*Таємниці Підземелля*, *Мисливець за Реліквіями*, *Поціновувач Новинок*, *Сейф Сховища й ВІП-Диско*, *Король Гірської Траси*, *Спостерігач Долини*).
- **Меню налаштувань**:
  - Вкладки **Дисплей** (роздільна здатність, віконний/повноекранний режим, VSync, ліміт FPS) та **Графіка** (пресети 0–5, render scale, згладжування, тіні, SDFGI/SSAO/SSR/Bloom/туман, щільність рослинності, дальність, погода, гучність).

## Встановлення та запуск (Windows)

Можна завантажити з репозиторію **лише один файл `RUN.bat`** і запустити його — він автоматично перевірить і завантажить:
1. Відсутні файли гри з GitHub (без потреби в установленному `git`);
2. **Godot 4.7.2-stable**, плагіни (`Terrain3D`, `Sky3D`, `SimpleGrassTextured`, `CosmoTreeGen`), усі PBR-текстури та 3D-моделі (`curl.exe` + `tar.exe` на чистому `cmd`);
3. Конфігурацію `game/config.cfg` та імпорт асетів.

Коли все на місці, `RUN.bat` одразу відкриває вибір режиму запуску з **5-секундним таймером автозапуску** (за замовчуванням обирається останній використаний режим):
- **1. DirectX 12 (Forward+)**
- **2. Vulkan (Forward+)**
- **3. OpenGL 3 (Сумісність)**

Керування меню: `↑` / `↓` (зупиняє таймер), `1–3` (миттєвий запуск), `Enter` (запуск), `Esc` (вихід).

## Керування

| Дія | Клавіші |
|---|---|
| Рух / Спринт / Стрибок | `WASD` або стрілки / `Shift` / `Пробіл` |
| Взаємодія (картини, триноги, карта, слоти, рулетка, бінокль, болід) | `E` або `ЛКМ` |
| 3D-Рулетка | Ставки мишею, `Пробіл` — крутити, `Esc` — встати |
| Журнал квестів / Ліхтар / Пауза | `Q` / `F` / `Esc` |
| Болід на трасі | `W/S/A/D` кермо, `Shift`/`Пробіл` нітро, `V` камера, `R` повернення на трек, `Esc` вихід |

## Автоперевірка

```bat
godot\Godot_v4.7.2-stable_win64_console.exe --headless --path game res://scenes/self_check.tscn
```
